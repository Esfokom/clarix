# Clarix Editing Qualification Corpus

This directory contains only PDFs generated by Clarix test tooling and a
manifest describing optional, locally supplied qualification cases.

Never commit customer documents, copyrighted files without a redistribution
license, credentials, secrets, personal data, or extracted document text.
Generated fixtures belong in `generated/`. Private licensed fixtures belong in
the ignored `local/` directory and must never be staged.

The Windows Phase 0 qualification run requires `local/embedded-truetype.pdf`
and `local/subset-font.pdf` on the qualification machine. Committed reports may
contain only their SHA-256 hashes, timings, object counts, capability results,
warnings, and stable error codes. They must not contain the PDF bytes, paths,
font bytes, or extracted text.

Run the repository generator described in
`docs/testing/editing-phase0-corpus.md` before qualification. Do not hand-edit
generated PDFs.
